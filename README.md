# ITRS prototype

Prototipo installabile dell'app ITRS per i test utente.

```bash
npm install
npm run dev      # http://localhost:5173, raggiungibile anche dal telefono in LAN
npm run build    # build in dist/
```

Nel browser l'app mostra la guida all'installazione. Per vedere l'app senza installarla: pulsante `Preview app here` in fondo alla guida, oppure `http://localhost:5173/?preview`. Indietro torna alla guida.

Regole di lavoro e struttura: vedi `CLAUDE.md`.
